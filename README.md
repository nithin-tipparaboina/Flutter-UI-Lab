# 🏋️ FitTrack — Flutter Fitness Tracking App

## 📌 Project Overview

**FitTrack** is a fitness tracking application developed using Flutter and Dart. The application demonstrates essential mobile app development concepts through a single, user-friendly interface.

The project combines fitness-related features with Flutter UI components, responsive layouts, form validation, navigation, state management, animations, and API integration. It was developed as part of a Flutter laboratory project to gain practical experience in mobile application development.

## 🎯 Project Objectives

* Learn the fundamentals of Flutter and Dart.
* Build interactive user interfaces using Flutter widgets.
* Implement responsive layouts for different screen sizes.
* Understand navigation and state management.
* Perform input validation using forms.
* Explore animations and reusable UI components.
* Demonstrate REST API integration.
* Combine multiple functionalities into one application.

## ✨ Key Features

* **Dashboard:** Overview of the app's main features.
* **BMI Calculator:** Calculate Body Mass Index using height and weight.
* **Calorie Calculator:** Estimate daily calorie requirements.
* **Workout Tracker:** Track workout-related activities.
* **Activity Counter:** Demonstrate state updates and interactive functionality.
* **Profile Form:** Collect and validate user information.
* **Responsive UI:** Adapt layouts to different screen sizes.
* **Animations:** Demonstrate animated UI elements.
* **Navigation:** Move between different app screens.
* **REST API Demo:** Demonstrate fetching data from an API.

## 🚀 How to Run the Project

1. Install Flutter and configure the development environment.

2. Clone the repository:

   ```bash
   git clone https://github.com/nithin-tipparaboina/Flutter-UI-Lab.git
   ```

3. Open the project directory:

   ```bash
   cd Flutter-UI-Lab
   ```

4. Install the dependencies:

   ```bash
   flutter pub get
   ```

5. Run the application:

   ```bash
   flutter run
   ```
